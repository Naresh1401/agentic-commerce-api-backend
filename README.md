# Commerce REST API Backend

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

FastAPI grocery commerce APIs for products, inventory, pricing, coupons, carts, checkout, orders, health, and metrics.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
